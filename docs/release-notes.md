# ChatArchiveTool v0.1.6

修复 Mac 关闭浏览器页面后，再次双击 App 没反应的问题。新增原生 macOS 启动层处理重新打开事件，复用正在运行的服务，保留导出任务；菜单栏提供“打开聊天档案”和“退出 ChatArchiveTool”。

点击界面的“退出工具”会同时退出原生 App；菜单栏退出会先等待后台任务停止和清理，再结束进程。下次启动使用新的地址，不复用失效端口。安装新版前请先在旧版页面点击“退出工具”。

保留 v0.1.5 的微信授权直连流程和媒体导出。提供 Windows x64、Apple 芯片 Mac、Intel Mac 下载包。Mac 包尚未 Apple 公证；首次打开说明见 README。

验证包含原生 AppKit 重新打开回调、同一实例重复打开、页面退出、再次启动、菜单栏退出和无残留后台进程。实际微信兼容性仍需用户自行验证；本次不操作用户微信。
