01 / 开始
第一次使用，先做什么？
  1. 在“聊天导出”选择 QQ 或微信。电脑上要有你自己的聊天记录；手机历史消息不会自动全部出现在电脑。
  2. 按对应的连接说明准备。已经有导出文件的，选择“导入文件”。
  3. 选择好友或填写好友备注，再选择日期和保存位置。第一次建议先导出几天，确认结果。
  4. 点击“开始导出”，等待完成后点击“查看档案”。
  5. 要了解聊天情况，去“关系分析”读取档案、选择哪位是你和关系类型，先试“本地基础分析”。无需付费 API。

 
02 / QQ
QQ 已登录，为什么还要准备？
普通 QQ 不提供本工具可直接使用的导出接口，需要额外的 QQ 导出组件。“连接失败”通常是组件没有安装、没有启动或还没扫码。
  1. Apple 芯片 Mac：先在 QQ 左上角菜单选择“退出 QQ”，也可按 ⌘Q。点红色关闭按钮只会关窗口。组件使用独立副本，但共享本机 QQ 数据，不能与普通 QQ 同时运行。
  2. 点击“准备并连接 QQ”。工具会下载并校验组件，已安装的会跳过下载。下载较慢时可在“处理记录”查看进度。
  3. 会出现一个终端窗口。保持它打开，在手机 QQ 扫描其中的二维码，确认是你自己的账号。
  4. 回到本工具，自动出现好友与群聊后即可选择。等待超时也不用重装，扫码完成后再次点击连接。
Windows 也使用同一入口；Intel Mac 暂无内置 QQ 原生组件，可连接已经部署的本机服务或导入文件。通常不需要改 QCE 地址和访问令牌，它们会自动使用本机设置。

 
03 / 微信
Mac 微信：导出文字、图片和视频
v0.1.5 参考 wechat-exporter-mac 的数据库和图片格式。适配微信 4.x，本机处理，无需配置 API、安装 Python 或输入终端命令。实际兼容性取决于微信版本，首次建议用“文件传输助手”的少量测试消息。
  1. 把新版 ChatArchiveTool.app 拖到“应用程序”，从那里打开。确认右上角版本为 v0.1.6。
  2. 选“微信 → 直接导出”，阅读签名修改说明并勾选确认。在微信菜单点“退出微信”，或按 ⌘Q；仅关窗口不够。
  3. 点“1. 准备读取”。工具先备份微信程序，再通过 macOS 系统弹窗请求授权修改程序签名。输入的是 Mac 管理员密码，不是微信密码。截图、录屏权限可能需要重新授权；不会关闭 SIP。
  4. 点“2. 打开微信并登录”，按微信提示完成登录。打开要导出的聊天，先查看需要保存的图片和视频，等待下载。
  5. 回工具点“3. 连接并检查”，在系统弹窗授权读取。扫描不会附加调试器、暂停或退出微信。密钥仅保存在本机，不会进入日志或聊天档案。
  6. 填写准确好友备注、群名或 wxid，选择日期与保存位置，点击“开始导出”。完成后打开档案，检查文字、图片和视频，以及缺失媒体提示。
授权后失败怎么办？
先确认准备前已完全退出微信、准备后已重新登录并打开目标聊天。若提示文件权限，前往“系统设置 → 隐私与安全性 → 完全磁盘访问”允许 ChatArchiveTool，完全退出并重开工具。若系统仍拒绝进程读取，请停止反复授权；本工具不会建议关闭系统保护，也不能保证支持所有微信版本。微信升级或切换账号后需要重新连接。
如何恢复微信原程序？
先手动退出微信，勾选确认，点击“恢复微信程序”。只恢复本工具备份的同版本程序，不删除聊天数据。若微信已经升级或没有备份，请从微信官网下载当前版本覆盖安装程序，不要删除 Library 内的微信数据文件夹。
为什么有些媒体仍然缺失？
已过期、未下载、未同步到电脑的文件无法凭空恢复。程序按会话和消息标识关联媒体，不按文件顺序猜测；无法唯一关联时保留占位。图片支持本地 DAT 解码及部分 HEVC 图片转换，视频保存本机 MP4；语音尽量保存 WAV，无法解码时保留 SILK。贴图、其他附件的原文件提取暂不完整。缩略图会明确标注。手机历史记录须先迁移到电脑。
不想修改微信签名？
可切换“导入已有文件”，选择已有 chat_full_parsed.json 及同目录媒体，或微信原生 ZIP。原生分享是否可用由微信决定，只保存微信实际交出的内容，不能代替完整数据库导出。
Windows 微信
Windows 继续使用 wechat-chat-export：保持微信登录，安装组件后填写准确好友或群名。无需执行 Mac 的签名准备步骤。

 
04 / 系统设置
Mac 微信读取需要什么权限？
直接导出需要在 macOS 系统弹窗授权修改微信程序签名及读取登录进程。只在你主动点击对应按钮后请求，不会把密码存入工具。首次先手动退出微信，准备后重新登录；“连接并检查”不会主动退出微信。
若提示不能读取文件，到“系统设置 → 隐私与安全性 → 完全磁盘访问”添加 ChatArchiveTool，再完全退出并重开本工具。源码运行时需允许启动它的终端。无需关闭 SIP。
导入已有文件不需要读取微信进程；ZIP 分享只需要启用共享扩展。

 
05 / 终端
QQ 的文字窗口怎么用？
“终端”是 macOS 自带应用。QQ 导出组件用它显示二维码；正常操作无需自己输入命令。新版 Mac 微信直接导出使用系统授权弹窗，不使用终端。
  1. 准备 QQ 后，使用手机 QQ 扫描终端二维码，等待登录完成。
  2. QQ 导出期间保持该终端窗口打开。窗口被挡住时可用 ⌘Tab 切换到“终端”。
  3. 旧微信连接终端仍在等待 Password 时，可在那一个窗口按 Control+C 取消，再关闭。不要关闭正在导出的 QQ 窗口。
不要把密码、API Key、二维码、访问令牌或聊天内容贴到公开反馈中。

 
06 / AI 分析
API 的三个框，分别填什么？
API 可以理解为“让本工具请求你选的 AI 服务”。只有 AI 分析需要；导出和本地基础分析均不需要。AI 服务通常单独计费，请先在服务商网站确认用量与余额。
  1. 打开你选择的 AI 服务商官方网站，登录其“开放平台 / 开发者控制台”。在 API 密钥页面创建 Key，复制到本工具的“API Key”。不要填网站登录密码。
  2. 服务地址：从该服务商官方 API 文档复制兼容 Chat Completions 的地址。不能填写聊天网页地址。本工具可以自动补上 /chat/completions。
  3. 模型名称：复制官方文档或控制台提供的准确模型 ID，不能随意写昵称。
  4. 确认三项来自同一家服务商。选择 AI 分析后，也可用界面的 DeepSeek 地址按钮填入地址；仍需自己填写当前可用模型和该平台的 Key。
  5. 点击预览，检查要发送的聊天文字与服务商地址，勾选同意后才开始调用。不想发送聊天内容，可切回本地基础分析。
401 / 403
密钥或权限有问题，检查 Key 所属平台、是否有效。
404 / 模型不存在
核对服务地址、模型名称和该账号的模型访问权限。
429 / 额度不足
检查服务商余额、请求限额，稍后重试；不需要重新导出聊天。
API Key 在本次调用后清空。脱敏不能保证消除所有个人信息，请认真查看预览。

 
07 / 文件
保存位置、导入和换电脑
  1. “保存位置”会按当前电脑、当前用户生成，下载后不会指向开发者电脑。点击文件夹按钮可改到“文稿”或自己的其他目录。
  2. 完成后点“打开文件夹”。分享或备份时复制整个聊天档案文件夹，图片等媒体依赖相对位置，别只复制 HTML。
  3. 已有文件：选择“导入文件”。QQ 需要同一批导出的消息文件和媒体 ZIP；微信可选原生聊天 ZIP、聊天记录.txt，或 chat_full_parsed.json 及其所在文件夹。不是任意数据库或手机备份都能直接导入。
  4. “关系分析”可重新读取已经保存的档案，不必每次连接 QQ 或微信。
Mac 默认数据位于当前用户的“资源库 → Application Support → ChatArchiveTool”，导出放在其 exports 子目录。建议使用应用的文件夹按钮打开，不必在终端找路径。

 
08 / 排错
打不开 App，或操作没有结果？
关掉页面后，再次打开没反应？
Mac v0.1.6 起，关闭浏览器页面后再次双击 App 会重新打开界面，正在处理的任务会保留。也可点击屏幕顶部菜单栏“聊天档案 → 打开聊天档案”。要完全退出，点击工具左下角“退出工具”，或菜单栏“退出 ChatArchiveTool”；退出完成后可再次启动。安装新版前请先退出旧版后台。
Apple 无法验证 ChatArchiveTool
确认下载自本项目 GitHub Releases 后，先尝试打开一次，再到“系统设置 → 隐私与安全性”，找到本应用被阻止的提示，点击“仍要打开”，按系统要求确认。仅在你信任该来源时操作。本应用尚未完成 Apple 公证。查看 Apple 官方说明
为什么还有测试文件？
GitHub 源码中的 tests 用来检查功能。普通用户下载 Releases 中对应系统的桌面包即可，桌面包不包含这些开发测试文件，无需自己运行测试。
连接失败了，要重新安装吗？
通常不需要。QQ 先检查导出终端是否仍在运行、扫码是否完成；Mac 微信请按“准备读取 → 登录微信 → 连接并检查”操作，确认打开的是 v0.1.5 或更新版本。查看“处理记录”了解下载或处理进度。仍不能读取时，可导入其他兼容工具导出的文件。
聊天不完整或图片、语音缺失
先确认日期范围、当前账号，以及历史消息是否已经同步到电脑。没有加载到本机的内容无法凭空恢复。Mac 微信部分媒体暂不支持，档案会标注缺失原因；界面禁用的语音转写选项表示桌面包没有该可选引擎。
