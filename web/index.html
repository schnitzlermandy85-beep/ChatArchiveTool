01 / 开始
第一次使用，先做什么？
  1. 在“聊天导出”选择 QQ 或微信。电脑上要有你自己的聊天记录；手机历史消息不会自动全部出现在电脑。
  2. 按对应的连接说明准备。已经有导出文件的，选择“导入文件”。
  3. 选择好友或填写好友备注，再选择日期和保存位置。第一次建议先导出几天，确认结果。
  4. 点击“开始导出”，等待完成后点击“查看档案”。
  5. 要了解聊天情况，去“关系分析”读取档案、选择哪位是你和关系类型，先试“本地基础分析”。无需付费 API。

 
02 / QQ
QQ 已登录，为什么还要准备？
普通 QQ 不提供本工具可直接使用的导出接口，需要额外的 QQ 导出组件。“连接失败”通常是组件没有安装、没有启动或还没扫码。
  1. Apple 芯片 Mac：先在 QQ 左上角菜单选择“退出 QQ”，也可按 ⌘Q。点红色关闭按钮只会关窗口。组件使用独立副本，但共享本机 QQ 数据，不能与普通 QQ 同时运行。
  2. 点击“准备并连接 QQ”。工具会下载并校验组件，已安装的会跳过下载。下载较慢时可在“处理记录”查看进度。
  3. 会出现一个终端窗口。保持它打开，在手机 QQ 扫描其中的二维码，确认是你自己的账号。
  4. 回到本工具，自动出现好友与群聊后即可选择。等待超时也不用重装，扫码完成后再次点击连接。
Windows 也使用同一入口；Intel Mac 暂无内置 QQ 原生组件，可连接已经部署的本机服务或导入文件。通常不需要改 QCE 地址和访问令牌，它们会自动使用本机设置。

 
03 / 微信
微信：先确认系统支持
Mac 原版微信：如果界面提示“当前原版 Mac 微信不支持此直读方式”，请停止重复输入密码。完全磁盘访问只允许读文件，不能解除微信进程保护。上一版的“连接已登录微信”无法解决这个限制。
可复用的上游流程：wechat-chat-export 官方目前支持 Windows。在 Windows 电脑微信中准备好记录，使用该工具导出，再将包含 chat_full_parsed.json 和 media 的整个文件夹复制到 Mac。在本工具选择“整合已有导出”，选中该文件夹即可保存档案并分析。没有 Windows 或已有导出文件时，目前没有经验证的 Mac 原版微信直读方案。
仅在界面允许实验性连接时
微信的本机聊天数据库经过加密，登录成功不代表其他软件有读取权限。Apple 芯片 Mac 提供实验性读取：尝试连接当前微信，不主动退出或重签微信。系统拒绝时会停止并说明原因。
  1. 打开日常使用的电脑微信并登录，进入想导出的聊天，等待消息加载。
  2. 回本工具，选择微信，点击“准备微信组件”。安装结束后点击“连接已登录微信”。
  3. 在弹出的终端中按提示输入 Mac 登录密码，按回车。输入时没有字符或星号，这是正常现象。
  4. 回微信打开目标聊天，并向上翻几页历史记录。约一分钟后，本工具显示验证结果。
  5. 检查通过后填写准确的好友备注、昵称或群名，开始导出。同名时可使用微信内部账号标识 wxid。
如果密码后立即失败，先看连接卡片的具体原因，通过对应按钮检查权限；不要连续输密码或退出微信。当前版本仍不兼容时，请使用已有导出文件。旧版“初始化”会切换微信副本，本版已经移除此入口。
多账号电脑：在“连接与来源设置”选择当前账号的 db_storage 文件夹。换账号需要重新连接。当前 Mac 支持文字与可提取图片；其他媒体保留占位，不会伪装成已经导出。Intel Mac 使用导入模式。

 
04 / 系统设置
Mac 权限怎么开？
只在界面明确提示缺少相应权限时操作。设置名称可能随 macOS 版本略有变化。
  1. 读不到微信文件：系统设置 → 隐私与安全性 → 完全磁盘访问 → 打开“终端”。没有终端时点加号，在“应用程序 → 实用工具”中选择它；可能需要 Mac 密码或指纹确认。
  2. 拒绝读取微信进程：先看微信读取条件检查。原版微信的强化运行时保护不能通过开启“开发者工具”解除，不要为此反复授权。仅对明确允许调试读取的环境，开发者工具权限才可能有关。
  3. 缺少系统工具：点击下面“安装系统工具”，在 Apple 弹窗中选“安装”，等待完成。无需下载完整 Xcode。
  4. 改完权限，先完成或取消本次连接，然后退出终端并重新连接。不要关闭正在工作的 QQ 导出终端；可等 QQ 导出结束后再设置。
本工具不会要求关闭 SIP，也不会自动改签微信。如果不想授予读取权限，可以使用导入模式。

 
05 / 终端
弹出的文字窗口怎么用？
“终端”是 macOS 自带的应用，本工具通过它显示二维码或系统授权。正常使用无需自己复制、输入命令。
  1. 窗口显示 Password 时，输入这台 Mac 的开机登录密码，再按回车。没有字符回显，仍是在输入；不是微信密码，也不是 API Key。
  2. 想取消时，在该终端按 Control+C。正在连接微信时，也可先点本工具的“取消本次连接”；若仍在等密码，再按 Control+C。
  3. QQ 导出期间保持其终端窗口打开。微信显示连接完成后，可以关闭本次连接窗口。
  4. 窗口被挡住时，点下方“显示终端”，或者用 ⌘Tab 切换应用。窗口有错误时，先看本工具里的步骤说明。
不要把密码、API Key 或微信读取密钥发给别人。寻求帮助时只发送错误提示，截图时遮住二维码、令牌和个人信息。

 
06 / AI 分析
API 的三个框，分别填什么？
API 可以理解为“让本工具请求你选的 AI 服务”。只有 AI 分析需要；导出和本地基础分析均不需要。AI 服务通常单独计费，请先在服务商网站确认用量与余额。
  1. 打开你选择的 AI 服务商官方网站，登录其“开放平台 / 开发者控制台”。在 API 密钥页面创建 Key，复制到本工具的“API Key”。不要填网站登录密码。
  2. 服务地址：从该服务商官方 API 文档复制兼容 Chat Completions 的地址。不能填写聊天网页地址。本工具可以自动补上 /chat/completions。
  3. 模型名称：复制官方文档或控制台提供的准确模型 ID，不能随意写昵称。
  4. 确认三项来自同一家服务商。选择 AI 分析后，也可用界面的 DeepSeek 地址按钮填入地址；仍需自己填写当前可用模型和该平台的 Key。
  5. 点击预览，检查要发送的聊天文字与服务商地址，勾选同意后才开始调用。不想发送聊天内容，可切回本地基础分析。
401 / 403
密钥或权限有问题，检查 Key 所属平台、是否有效。
404 / 模型不存在
核对服务地址、模型名称和该账号的模型访问权限。
429 / 额度不足
检查服务商余额、请求限额，稍后重试；不需要重新导出聊天。
API Key 在本次调用后清空。脱敏不能保证消除所有个人信息，请认真查看预览。

 
07 / 文件
保存位置、导入和换电脑
  1. “保存位置”会按当前电脑、当前用户生成，下载后不会指向开发者电脑。点击文件夹按钮可改到“文稿”或自己的其他目录。
  2. 完成后点“打开文件夹”。分享或备份时复制整个聊天档案文件夹，图片等媒体依赖相对位置，别只复制 HTML。
  3. 已有文件：选择“导入文件”。QQ 需要同一批导出的消息文件和媒体 ZIP；微信选择 chat_full_parsed.json 或其所在文件夹。不是任意数据库或手机备份都能直接导入。
  4. “关系分析”可重新读取已经保存的档案，不必每次连接 QQ 或微信。
Mac 默认数据位于当前用户的“资源库 → Application Support → ChatArchiveTool”，导出放在其 exports 子目录。建议使用应用的文件夹按钮打开，不必在终端找路径。

 
08 / 排错
打不开 App，或操作没有结果？
Apple 无法验证 ChatArchiveTool
确认下载自本项目 GitHub Releases 后，先尝试打开一次，再到“系统设置 → 隐私与安全性”，找到本应用被阻止的提示，点击“仍要打开”，按系统要求确认。仅在你信任该来源时操作。本应用尚未完成 Apple 公证。查看 Apple 官方说明
为什么还有测试文件？
GitHub 源码中的 tests 用来检查功能。普通用户下载 Releases 中对应系统的桌面包即可，桌面包不包含这些开发测试文件，无需自己运行测试。
连接失败了，要重新安装吗？
通常不需要。QQ 先检查导出终端是否仍在运行、扫码是否完成；微信按连接卡片提示检查权限与当前账号。查看“处理记录”了解下载或处理进度。仍不能读取时，可导入其他兼容工具导出的文件。
聊天不完整或图片、语音缺失
先确认日期范围、当前账号，以及历史消息是否已经同步到电脑。没有加载到本机的内容无法凭空恢复。Mac 微信部分媒体暂不支持，档案会标注缺失原因；界面禁用的语音转写选项表示桌面包没有该可选引擎。
