# ChatArchiveTool

面向 Windows 的 QQ／微信聊天归档与双人关系分析工具。已有导出可以直接载入；选择朋友、亲人、恋人或闺蜜／亲密朋友，生成中文双栏 HTML 报告。

本仓库保存程序源码、测试与合成示例。语音模型、安装后的运行组件、个人聊天档案和 API 密钥保存在本地。

## 功能

- 导出或整合 QQ／微信聊天，关联图片、表情、音频及已有语音转写。
- 直接读取 QQChatExporter JSON、JSONL、带 `manifest.json` 的分块目录或 ZIP，以及本工具 `messages.jsonl` 档案。
- 本地基础分析：消息节奏、会话发起、回应间隔、文字表达和关键词候选观察，无需 API。
- AI 分析：兼容 Chat Completions 协议的 HTTPS 服务及本机服务。所选日期内全部有效文字与已有转写按时间完整分批，再综合已校验结果。
- 按关系配置心理学主理论与辅助理论，共用八个观察维度，区分行为与解释，不提供依恋类型诊断或心理评分。
- 离线 HTML 报告：中文双栏正文、3D 日期热力图、日内时段图、媒介构成图和双方行为表；可打印为 PDF。

## 启动与体验

推荐 Windows x64、Python 3.12（包含 Tkinter），并安装 Edge、Chrome 或其他浏览器。源码尚未打包为独立 EXE。

1. 克隆仓库或下载 ZIP 后完整解压，进入项目根目录。
2. 双击 `start.cmd`。它优先使用 `.venv`，其次使用 `py -3.12`，最后尝试 PATH 中的 Python。
3. 保持启动窗口运行。若浏览器没有打开，双击生成的 `打开界面.html`，或复制启动窗口中的本机网址到浏览器。
4. 进入“关系分析”，选择 `examples/synthetic-chat`，读取身份并生成本地报告。该数据完全由程序合成。

命令行启动与检查：

```powershell
py -3.12 app.py --check
py -3.12 app.py
# 只启动本机服务，手工访问控制台网址
py -3.12 app.py --no-browser
```

启动失败请查看 `logs/startup.log`。2026-10-08 已修复浏览器快速失败被误判成功和浏览器打开阻塞本地服务的情况；自动回退失败时保留手工入口。

本地基础分析及关系 AI 调用只使用 Python 标准库，可以先直接体验。需要新语音转写或微信直接读取时，再安装对应组件。

## 可选运行组件

本地语音识别：

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

首次使用未下载的语音模型需要联网；可在界面中指定已下载的模型目录。微信直接读取组件通过界面“安装 / 修复微信组件”安装到项目内 `.wechat-packages`。组件依赖本机微信版本与账号状态；真实微信数据库尚未纳入验证。QQ 直接导出需要用户自行运行并登录 QQChatExporter，本工具通过其本机 API 调用。

## 分析流程

读取档案 → 确认哪位是你 → 选择关系与日期 → 本地报告，或填写 AI 地址、模型 ID、API Key → 核对每批发送内容与综合规则 → 生成报告。

API 服务地址可以是根地址、`/v1` 地址或完整 `/chat/completions` 地址。填写实际服务商支持的模型 ID。DeepSeek 地址按钮仅是快捷填入，不限制服务商。本机 HTTP 服务允许空密钥，远程服务使用 HTTPS 和密钥。

AI 分析按消息完整分批，不抽样或截断。大消息超过请求上限时明确提示；全部批次与综合成功后才标记全量完成。调用失败会注明实际完成情况，并回退本地统计。补充分析要求最多 2000 字符，修改后需要重新核对预览。长记录会产生多次服务商调用及相应费用。

报告保存到输入档案所在目录的 `relationship-reports/时间-随机标识/`，包含离线 `report.html` 和结构化 `report-data.json`。报告移除了原文证据附录和局限章节；内部消息引用校验仍保留。公开报告数据不包含完整聊天预览、原文附件或 API 密钥。

## 心理学观察框架

| 关系视角 | 主理论 | 辅助视角 |
| --- | --- | --- |
| 亲人 | 家庭系统理论 | 角色理论、依恋理论 |
| 恋人 | 依恋理论 | Sternberg 爱情三角理论、相互依赖理论、Gottman 伴侣互动研究 |
| 朋友 | 社会交换理论 | 社会渗透理论、互惠规范、关怀性与交换性关系区别 |
| 闺蜜／亲密朋友 | 社会渗透理论 | 自我表露、社会支持、共同反刍研究 |

统一观察：亲近寻求与回应、角色义务与期待、自我表露与接纳、互惠协调、关系边界与约定、情绪支持、共同活动、未来计划与承诺。主辅配置是产品的观察顺序，关系视角由用户选择；不自动判断双方真实关系，不强行补齐证据不足的维度。

每条解释连接具体行为、理论与其他可能原因。双方画像只描述这段记录中的表达与回应；沟通需要写成可询问、可协商的问题。不把回复速度当作依恋类型、秘密数量当作信任、消息对半当作友情公平，或反复倾诉直接当作共同反刍。引用校验和多片段标签是工程规则，不能证明心理解释正确。

完整内置要求及核验过的来源见 [心理学分析要求](docs/psychology-requirements.txt)。

## 隐私

本地模式不上传聊天。AI 模式发送用户核对并确认的脱敏文字与统计；不发送媒体文件、本地源路径或原始消息对象。自动脱敏无法识别所有事件与姓名，发送前请检查预览。API Key 仅用于当次调用，不写入配置、报告或日志。聊天正文属于不可信输入，不能改变固定的分析规则。

`.gitignore` 排除运行组件、模型、真实导出、报告、日志、临时文件、环境文件与常见密钥文件。仓库中的聊天数据只保留明确标记的合成示例。

## 开发与验证

完整回归测试额外需要 Pillow，用于验证微信表情缓存关联；不需要下载语音模型或安装微信读取组件：

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.venv\Scripts\python.exe run_tests.py
# 仅运行关系模块
.venv\Scripts\python.exe -m unittest discover -s tests -p "test_relationship*.py" -v
```

已有 Node.js 时可执行 `node tests/ui_smoke.cjs`，验证真实前端脚本的交互逻辑。这不等同于浏览器视觉检查。验证范围见 [验证说明](docs/validation.md)，模块职责见 [项目结构](docs/architecture.md)。
