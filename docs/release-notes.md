# ChatArchiveTool v0.1.5

Mac 微信新增参考 wechat-exporter-mac 的直接导出流程，读取本机文字、图片、视频；保留已有文件导入。支持当前用户目录，不包含开发者的保存路径、密钥或聊天数据。

首次需明确勾选签名修改说明、手动退出微信，再准备读取、重新登录、连接并检查。系统弹窗授权替代终端密码；工具不主动退出微信，不关闭 SIP。签名修改可能影响微信权限，提供原程序备份及同版本恢复入口。

修正上游单分片读取、WAL 最新消息遗漏、按顺序配图与未按会话关联视频的问题。原文件缺失、关联不唯一、解码失败会显示原因，不把文件保存当成完整导出。语音尽量保存 WAV，不能解码时保留 SILK；贴图与其他附件提取仍有限。

请选择 Windows-x64、macOS-AppleSilicon（M 系列）或 macOS-Intel。Mac 包尚未 Apple 公证，可信来源下载后可按 README 的“仍要打开”说明操作。

验证区分：合成加密数据库/文字/图片/视频、界面和安装包检查不等于真实微信适配验证；真实登录和导出由用户自行测试，建议先用文件传输助手。
