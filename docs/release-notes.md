# v0.1.8 本地截图导入

新增 Mac Apple Vision 本地文字识别、人工核对、多行合并、截图和消息排序、疑似重叠提示及媒体框选裁片。导出保留原截图、JSONL 和离线浏览页；未知时间和身份明确保留，禁止用不完整身份/时间开放关系分析。没有恢复语音、视频、原图或动图的能力。现有 QQ/Windows 微信流程保留。

# ChatArchiveTool v0.1.7

Mac 微信改为官方“导出到电脑”分步引导：手机选择好友或群聊，传输后在电脑微信中查看。停用旧版微信签名准备、密钥扫描和直连接口，安装包不再携带进程扫描器。

这条流程不会生成 ChatArchiveTool 的 HTML / JSON 档案，暂不能直接用于关系分析。已有兼容文件仍可整合；Windows 微信与 QQ 的导出流程保留。帮助中补充官方传输、媒体缺失、旧版微信恢复说明。以前安装过修改版微信的用户，需通过官方渠道替换回微信客户端；升级本工具不会自动恢复微信。

保留 Mac 关闭页面后再次打开、菜单栏打开及退出功能。按电脑选择 Windows x64、Apple 芯片 Mac 或 Intel Mac 安装包。

Mac 尚未 Apple 公证：从本仓库下载并信任来源后，将 App 放入“应用程序”；如首次打开被拦截，按 README 的“Apple 无法验证”说明操作。
